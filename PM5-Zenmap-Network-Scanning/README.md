\# PM5 – Network Scanning with Zenmap



\## Overview



This module focuses on network discovery and scanning using Zenmap, the graphical interface for Nmap.



The practical activities were conducted within an authorized local VirtualBox network lab.



\## Testing Environment



\- Operating System: Kali Linux

\- Virtualization: Oracle VirtualBox

\- Network: Local virtual network lab

\- Scanning Tool: Zenmap / Nmap



\## Activities Performed



\### 1. Network Discovery

Identified active hosts within the authorized lab network.



\### 2. Host Identification

Observed discovered hosts and available network information.



\### 3. Port Scanning

Examined scan results to identify reported open ports and services.



\### 4. Network Topology

Used Zenmap's topology visualization to understand relationships between discovered hosts.



\### 5. Result Documentation

Saved scan outputs and screenshots for technical documentation.



\## Evidence Directory



\- `Scan-Results/` – Saved Zenmap scan output.

\- `Network-Topology/` – Topology evidence.

\- `Screenshots/` – Scanning and host discovery screenshots.



\## Learning Outcomes



\- Understanding network discovery.

\- Identifying active hosts.

\- Interpreting Nmap scan results.

\- Understanding port scanning.

\- Visualizing network topology.

\- Documenting network assessment results.



\## Authorization Disclaimer



All scanning activities were performed within the authorized local virtual network lab for educational purposes.



No unauthorized external systems were intentionally scanned.
