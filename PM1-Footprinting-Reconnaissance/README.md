\# PM1 – Footprinting and Reconnaissance



\## Overview



This module focuses on practical footprinting and reconnaissance techniques using Kali Linux tools.



The objective was to understand how publicly accessible information, DNS records, website technologies and HTTP responses can provide useful information during security assessments.



\## Tools Used



| No. | Tool | Purpose |

|---|---|---|

| 01 | WHOIS | Domain registration information |

| 02 | WhatWeb | Website technology fingerprinting |

| 03 | Nslookup | DNS queries and resolution |

| 04 | cURL | HTTP response and header inspection |

| 05 | wafw00f | Web Application Firewall detection |

| 06 | DNSRecon | DNS enumeration |



\## Activities Performed



\### 1. WHOIS

Collected domain registration information and examined available registration details.



\### 2. WhatWeb

Identified website technologies and publicly observable technology indicators.



\### 3. Nslookup

Performed DNS queries to understand domain name resolution.



\### 4. cURL

Inspected HTTP responses and response headers.



\### 5. wafw00f

Checked for indications of Web Application Firewall protection.



\### 6. DNSRecon

Performed DNS reconnaissance and examined available DNS information.



\## Evidence



Each tool has its own directory containing:

\- Command output (`output.txt`)

\- Screenshots of execution and results



\## Learning Outcomes



\- Understanding passive and active reconnaissance.

\- Learning DNS information-gathering techniques.

\- Identifying publicly exposed technology information.

\- Understanding HTTP headers and responses.

\- Recognizing the security value of reconnaissance.
